# Initial Submission Release Notes

Glenski Assurance Suite is an initial skills-only plugin submission.

It packages four reusable workflows: Cross Platform Compliance, Universal Software Audit, Python Web App Security Audit, and Human Writer. The package contains no MCP server, hosted service, telemetry, customer data connection, or credential requirement.

All included skills were validated locally with their final file tree. The security test suite is included as a reusable test resource and must be configured against the installer's authorized application before it can run.
